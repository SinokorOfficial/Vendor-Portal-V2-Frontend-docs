    시작하기¶

    로그인¶

    1. 포털 주소로 접속하면 로그인 화면이 표시됩니다.
    2. 사번(USER ID) 과 비밀번호를 입력하고 로그인합니다.
    3. 로그인에 성공하면 업무 화면으로 이동합니다. 일정 시간 미사용 시 자동으로 로그아웃되며, 이때는 다시 로그인하면 됩니다.

    로그인이 풀릴 때

    화면 조작 중 갑자기 로그인 화면으로 돌아가면 세션이 만료된 것입니다. 다시 로그인 후 이어서 작업하세요(작성 중이던 내용은 저장 전이라면 유지되지 않을 수 있습니다).

    화면 구성¶

    로그인 후 화면은 세 영역으로 나뉩니다.

    ┌──────────────────────────────────────────────┐
│  상단바 (로고 · 회사/사용자 · 언어)              │  ← 헤더
├───────────┬──────────────────────────────────┤
│           │  [탭1] [탭2] [탭3] ...             │  ← 열린 화면 탭
│  좌측     ├──────────────────────────────────┤
│  메뉴     │                                  │
│  (트리)   │   화면 내용 (검색조건 + 표)        │
│           │                                  │
└───────────┴──────────────────────────────────┘
    • 상단바 — 로고, 현재 회사/사용자, 언어 전환.
    • 좌측 메뉴 — 업무 메뉴 트리. 접기/펴기가 가능합니다.
    • 탭 영역 — 선택한 화면이 탭으로 열립니다(여러 화면 동시 작업).

    메뉴 / 탭 사용¶

    • 좌측 메뉴에서 항목을 클릭하면 해당 화면이 새 탭으로 열립니다.
    • 이미 열려 있는 화면은 그 탭으로 전환됩니다.
    • 탭을 닫으려면 탭의 닫기(×)를 누릅니다.
    • 같은 화면을 여러 벌 열어 비교 작업할 수 있습니다(복제 탭).

    회사 / 고객 컨텍스트¶

    상단의 회사(법인) 선택은 화면 조회 범위에 영향을 줍니다. 데이터가 예상과 다르면 현재 선택된 회사/고객이 맞는지 먼저 확인하세요.

    다음 단계¶

    모든 화면에 공통인 조회·그리드·엑셀·파일 조작은 공통 화면 사용법에서 한 번에 익힐 수 있습니다.
