    라우팅¶

    파일 기반 라우팅 (unplugin-vue-router)¶

    라우트는 src/pages/** 파일 구조에서 자동 생성됩니다(vite.config.ts).

    // vite.config.ts
VueRouter({
  routesFolder: 'src/pages',
  dts: 'src/typed-router.d.ts'   // 라우트 타입 자동 생성
})

    경로 → URL 규칙¶

    파일 URL
    src/pages/index.vue /
    src/pages/eir/EirExportIssue/index.vue /eir/EirExportIssue
    src/pages/cms/popup/CmsEmailPopup/index.vue /cms/popup/CmsEmailPopup
    src/pages/[...path].vue /:path(.*) (catch-all)
    src/pages/<...>/[id].vue /<...>/:id (동적 세그먼트)

    폴더 안의 index.vue 는 그 폴더 경로가 곧 라우트가 됩니다. 전체 매핑은 라우트 표에서 자동 생성됩니다.

    props 주입¶

    라우터는 모든 라우트에 props: true 를 부여해, 라우트 파라미터와 codeMap(코드 프리페치 결과) 를 화면 props 로 넣어줍니다 (src/router/index.ts). 화면은 pageMixin 을 통해 codeMap prop 을 받습니다.

    가드 체인¶

    라우팅 시 아래 가드가 순서대로 실행됩니다.

    tabGuard ─▶ menuAuthGuard ─▶ codeDataGuard ─▶ 화면 진입
    1. tabGuard (src/util/tabs/tabGuard) — /copyN 형태의 멀티탭/복제 라우트를 처리.
    2. menuAuthGuard (src/router/menuAuthGuard.ts) — 메뉴 권한 검사.
    3. /, /login, /popup/ 는 통과.
    4. 부트스트랩(menuMap) 완료를 대기.
    5. 쿼리 ?mid=MENU_ID 가 menuStore 에 존재하는지 확인 → 없으면 / 로 리다이렉트.
    6. activeTabMap 및 to.meta.title = MENU_NM 설정.
    7. codeDataGuard (src/router/guards.ts) — 화면의 정적 codeData() 가 선언한 공통코드를 프리페치해 to.meta.codeMap 에 채움(실패 시 진입 거부).

    메뉴 이동 패턴

    좌측 메뉴 클릭 → router.push({ path, query: { mid: MENU_ID } }) → 가드 검증 → 화면 로드. 즉 메뉴 권한은 mid 쿼리 + menuMap 으로 검증됩니다.

    멀티탭¶

    tabs 스토어(src/stores/tabs.ts)가 열린 탭 목록·활성 탭·복제 카운트를 관리하고, TabWorkspace(src/components/manual/app/EMain/TabWorkspace.vue)가 탭별 화면을 렌더합니다. 같은 화면을 여러 번 열기 위한 /copyN 경로를 tabGuard 가 처리합니다.
