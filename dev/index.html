    개발자 문서 — 개요¶

    Vendor Portal V2 프론트엔드의 기술 문서입니다. 신규 합류자가 화면 한 개를 만들고 배포하기까지 필요한 구조·규칙을 설명합니다.

    문서 작성 정책

    • 사내 전용 정보 금지 — 이 문서는 Vendor-Portal-V2-Frontend-docs 공개 레포로 발행된다. 내부 IP·호스트명·계정·실운영 문서를 본 공개 문서에 올리지 않는다. 실제 엔드포인트/시크릿은 문서에 쓰지 않고(placeholder 사용), 실값은 비공개 레포의 gitignore된 .env*에만 둔다.
    • 한국어 · MkDocs Material — 문서는 한국어로 작성하고, 조직 표준 문서 도구인 MkDocs Material(theme: material, language: ko)을 따른다. (사용자 매뉴얼·개발자 문서 공통)

    한눈에 보는 스택¶

    영역 채택 비고
    빌드 Vite 5 Node 20 필요
    프레임워크 Vue 3 화면은 Options API + mixin 패턴
    언어 TypeScript 5 핵심 인프라(router/stores/util)는 TS, 화면 index.vue/dataset.js 는 JS 위주
    UI Vuetify 3.7 앱 셸(v-app/v-main 등)
    그리드 ag-grid 25.3 + DevExtreme 22.1.3 버전 고정(현행 유지)
    라우팅 unplugin-vue-router src/pages 파일 기반
    컴포넌트 자동등록 unplugin-vue-components u-* 등
    상태 Pinia src/stores
    HTTP axios src/util/http, /api 프록시

    마이그레이션 배경¶

    이 프로젝트는 레거시 Nuxt 2 / Vue 2 에서 Vite 5 / Vue 3 로 이관됐습니다(FE-01~). Nuxt 의 pages 컨벤션, components 자동등록, proxy 설정을 1:1로 대체했기 때문에 디렉터리/관례가 Nuxt 와 유사합니다(vite.config.ts 주석 참고).
