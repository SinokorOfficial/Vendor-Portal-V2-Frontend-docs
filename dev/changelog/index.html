    변경 이력¶

    프론트엔드의 주요 변경을 기록한다. 상세 커밋은 git 로그를, 문제 해결 맥락은 트러블슈팅을 참고. 새 항목은 최신이 위로 오도록 해당 월 섹션에 추가한다.

    2026-07¶

    엑셀 다운로드 파일명 지정 스윕 + UI 개선 3건 + 문서 Partner Portal 브랜딩¶

    • 엑셀 다운로드 파일명·포맷 지정(PR #92) — 다수 화면의 exportExcel() 호출에 fileName(회사·화면명·yyyyMMdd)·exportMode: 'xlsx' 지정 → 다운로드 파일명이 화면별로 명확해짐(CMS/CRS/EIR/FDS/MVS/MDM/CFS 등).
    • 홈 대시보드 관리자 판정 전환(PR #92) — userId==='admin' 대신 세션 roleId 에 '1000-01'(관리자) 포함 시 AdminDashBoard 표시(관리자 역할 계정 전반 대응, 배열/문자열 방어 — EHeader isDocsRole 과 동일 계약).
    • CrsInvoice 레이아웃 개선(PR #92) — Invoice List↔Detail 사이 세로 splitpanes, Detail 테이블 폭 꽉 채움 + DRY~Total Cost 값 5열 균등 분배(table-layout:fixed 하 width 미지정 + 필러 col 제거), PRINT/DETAIL 버튼 우측정렬.
    • 로그인 ID 입력란 자동 포커스(PR #92) — 화면 진입 시 커서를 ID 칸에 둔다(mounted+ref).
    • 사용자 매뉴얼 문구 정리(PR #92) — manual-i18n 화면 제목·설명 표기 통일.
    • MkDocs 문서 사이트 Partner Portal 브랜딩(PR #92·#93) — 좌상단 로고/파비콘 V2 파비콘, 헤더·상단 탭 = 톤다운 블루(#2C6CB0)+흰 글자, 우상단 레포명 숨기고 github 아이콘만(라이트/다크 토글을 github 왼쪽으로·여백 통일), 좁은 화면에서도 github 를 헤더에 유지+드로어 제목 개행 2줄, 표기 Vendor Portal V2→Partner Portal(repo 주소·기술적 V2 보존).

    CI/CD hosted 복귀 + ag-grid/라우터 버그픽스 + 로그인로그 컬럼 정리¶

    • CI/CD GitHub-hosted(ubuntu-latest) 복귀(PR #85) — GitHub Actions 분 복구로 ci·deploy·docs-deploy 를 self-hosted → hosted 로 되돌림. 활성=hosted 원본(ci=Node20+vue-tsc/vite build+Trivy CVE+SBOM, docs=peaceiris), self-hosted(PowerShell/stub) 버전은 각 워크플로 하단 주석 블록으로 보관(각 줄 # 제거로 재전환). → 트러블슈팅 §9.
    • ag-grid 데이터 재로드 시 이전 셀 범위선택 잔존 해제(PR #81) — AgGridAdapter.setItems() 의 setRowData 직후 clearRangeSelection() 추가. ag-grid 25.3 의 setRowData 는 행 선택은 초기화하나 셀 범위(Ctrl+C 영역)는 남겨, 역할 전환 등 재로드 시 이전 하이라이트가 잔존하던 것을 전 그리드 공통 경로에서 해소. → 트러블슈팅 §6.5.
    • Home 탭에 이전 화면 버튼 잔존 해제(PR #82) — 관리자로 다른 화면 방문 후 Home 탭 클릭 시 직전 화면의 버튼이 대시보드에 함께 뜨던 버그. menuAuthGuard 의 /(Home) 진입에서 activeTabMap 을 초기화. → 트러블슈팅 §10.
    • 로그인 로그 프록시 컬럼 정리(PR #83) — CLIENT_IP 는 실제 사용자 공인 IP 로 정상 기록됨. 늘 비는 PROXY(2) 컬럼 숨김 + PROXY(1) → PROXY IP 라벨 명확화(백엔드 로직/조회 SQL 무변경, 표시만 조정). 아울러 EBtn modify 버튼 아이콘 오타 수정(mdi-contend-save→mdi-content-save, 렌더 안 되던 것).
    • 버튼 색 체계 리컬러링 스윕(PR #80·#86) — 업로드/인쇄/보조 버튼 색상 통일 + dev control 페이지 버튼 쇼케이스 3탭 구성.

    CI/CD self-hosted Windows 러너 이전 (배포 워크플로 PowerShell 이식)¶

    • GitHub Actions 분 소진 대응(PR #73·#74) — 호스티드 러너 월 쿼터 소진으로 deploy.yml 을 온프렘 self-hosted Windows 러너(runs-on: [self-hosted, Windows, vendor-portal-v2], shell: powershell)로 이식. 이미지 빌드는 az acr build(클라우드)라 러너엔 Git + PowerShell + Azure CLI 만 필요(Docker/Node 불필요). bash→PowerShell 이식: 콜론-변수 "$($env:X):tag" 서브식, $LASTEXITCODE 명시 판정, .env.production 복원은 UTF-8(BOM 없음)로 바이트 동일 재현. → 트러블슈팅 §9.
    • az acr build cp949 크래시 → 러너 시스템 로케일 UTF-8로 해결(PR #74 후속) — 한국어 Windows(cp949)에서 az acr build 가 vite 빌드로그의 ✓(U+2713)를 출력하다 UnicodeEncodeError 로 죽던 것을, 러너 시스템 로케일을 UTF-8(ACP=65001)로 바꿔 해결. env(PYTHONIOENCODING)로는 안 됨(az 가 번들 Python 을 격리 실행). → 트러블슈팅 §9.1.
    • ⚠️ ci.yml·docs-deploy.yml 은 아직 self-hosted 스텁(checkout만) — CI/문서배포 이식은 후속(러너 Node/Python + peaceiris(Docker 액션) 대체 필요). → §9.2.

    EIR execute 전환 + 로그인 첫 즐겨찾기 랜딩 + 대시보드 NOTICE 즐겨찾기버튼 숨김¶

    • EIR 3화면 공통 프로시저 통합 엔드포인트 전환(PR #71) — EirDemList·EirIssueStatus·EirResponseLog 의 selectVendorCommonProcedure → executeVendorCommonProcedure. 앞선 통합(ADR-0004)에서 제외됐던 EIR 마무리(잔여 EirExportIssue·EirImportIssue 는 범위 밖). 로컬 실환경 조회 스모크 ORA 0.
    • 로그인 직후 첫 즐겨찾기 메뉴로 랜딩(PR #71) — 즐겨찾기가 있으면 Home 대신 첫 즐겨찾기로 진입. 로그인 시 세팅하는 1회성 세션 플래그를 menuAuthGuard 의 / 진입에서 소비(이후 Home 탭 클릭 등 일반 진입은 대시보드 유지). role_id 가 1000 으로 시작하는 내부/관리자 계정은 제외(대시보드 유지).
    • admin 대시보드 NOTICE 탭 즐겨찾기(북마크) 버튼 숨김(PR #71) — EContentLayout 에 hideFavorite prop 추가 후, MdmNotice 를 대시보드에 임베드(<Notice :embedded="true"/>)할 때만 숨김. 독립 실행(/mdm/other/MdmNotice) 화면에선 그대로 노출(스코프 회귀 방지).

    미사용 화면 3종 제거 + 파일 로직 死코드 정리¶

    • 미사용 화면 3종 제거(PR #69, 백엔드 #49) — CmsMyBooking(내 부킹)·MdmPricingMgt(단가관리)·CmsGridLayoutCopyMgt(레이아웃 복사) 폴더 삭제(라우트 자동 제거) + CmsMyBooking 전용 EScheduler 컴포넌트(ESchedulerBookingItem·ESchedulerBookingItemTooltip) 제거. 공용 EScheduler 본체·HomeItem(대시보드 공유)·EGridLayoutAddon(전 그리드 컬럼 레이아웃)은 보존.
    • 파일 로직 死코드 정리(PR #69) — 호출 0 확인된 http.formUrl·http.fileDownByUrl·fileAixosInterceptor + FileService.getFile()·append() 제거.
    • CrsEstUploadExl 레거시 업데이트 반영(PR #69) — 테스트용 메서드 제거 + FM_UNIT/TO_UNIT 빈값 기본값(0.00)·필수검증 조정·검증 메시지 라벨(LENGTH→WIDTH) 수정.

    사용자 매뉴얼 화면(/manual) 추가¶

    • 레거시 가이드 시스템의 정적 사용자 매뉴얼을 V2로 이식(PR #68) — 헤더 MANUAL 버튼 → 새 탭 /manual. 좌측 네비 + 화면별 스크린샷 + 스텝/표/FAQ/단축키, 언어 전환(KO/EN/CN). pages/manual/{index.vue,manual-i18n.ts} + public/manual-screenshots/(V2 실화면 캡처, 좌측 메뉴 접힘).
    • 셸 없이 전체화면 — App.vue showShell + router/menuAuthGuard.ts 에 /manual 예외(레거시 layout:'blank' 동등).
    • 유저별 접근 메뉴 필터 — 각 화면 MENU_PATH 를 로그인 시 로드된 useMenuStore().menuMap(역할별) 과 교집합 → 접근 권한 있는 화면만 노출. 백엔드/DB/새 쿼리 없음.
    • 구 화면별 PDF MANUAL 버튼(EHeader openManual())은 주석 비활성 — 매뉴얼 페이지로 대체(로직 보존). 범위: 도메인 6모듈(TES/FDS/EIR/MVS/CFS/CRS), AI 챗봇 제외.

    死 선사(Carrier) 화면 제거 (BE 동반)¶

    • 선사 화면 제거(PR #65) — 백엔드 선사 기능 死(연결 DB에 TB_MDM_CARRIER/TB_CMS_CARRIER_SITE 부재, BE #45)에 대응해 MdmCarrierMgt(선사관리)·CmsCarrierSiteMgt(선사 사이트 관리) 화면 삭제 + 대시보드/MyBooking 스케줄러의 선사 로고 표시(imageServerLocation) 제거. reference/*는 배포 시 코드 기준 자동 재생성.

    파일 API 정리 (엔드포인트 개명 · FileService 死메서드)¶

    • /api/file/* 엔드포인트 verb-first 개명 반영(PR #62) — 백엔드 URL 개명(BE #44)에 맞춰 전 호출부 이관: FileService(uploadFile·uploadInvFile), 첨부 삭제 3화면(deleteFile), TES 템플릿 4화면(downloadTemplate4TES), 폐기 templateDown(downloadTemplate). ⚠️ API 경로 변경(breaking) — 백엔드와 동시 배포.
    • selectFileLists → selectFileList 흡수 반영(PR #62) — 다건 조회가 백엔드에서 단일 엔드포인트(동적 WHERE)로 통합돼 CmsInvoiceFileUploadPopup 호출부를 이관.
    • FileService 死메서드 정리(PR #61·#62) — 미사용 uploadGpt·downLogoImage·downBase64·down64(PR #61)와 rclUpload·saneiUpload(PR #62) 제거, uploadInv()→uploadInvFile() 로 백엔드와 명명 통일. TesInspExpn gpt 고아 체인도 제거(PR #61).

    공통 프로시저 호출 통합 (executeVendorCommonProcedure)¶

    • 조회/저장 통합 엔드포인트 전환(PR #58·#59) — select/saveVendorCommonProcedure → 통합 executeVendorCommonProcedure. EIR 제외 전 모듈(FDS·CRS·MVS·CFS·TES·CMS·MDM 등) 적용. 백엔드 배경은 ADR-0004. 호출 규약은 HTTP/API·화면 작성 패턴.
    • 날짜 셀 에디터(AgEDateBoxEditor) v-model 계약 교정(PR #58) — 레거시 :value/@input → v-model. @input 폴스루로 getValue() 가 DOM Event를 반환하던 버그(params.newValue.replace is not a function) 해결, 공유 에디터라 전역 정상화. → 트러블슈팅 §6.4.

    ag-grid 그리드 셀 편집 안정화¶

    • 셀 렌더러/에디터가 메인 앱 컨텍스트 상속(PR #45) — ag-grid 격리 셀 앱에 전역 컴포넌트(dx-*)·전역 프로퍼티($lang/$dialog)가 없어 코드박스 팝업 등이 크래시하던 것을 VueComponentFactory 패치로 근본 해결. → 트러블슈팅 §6.1.
    • 셀 에디터 mount/unmount 크래시 가드(PR #42) + 코드박스 셀 dx 렌더 복구(PR #44) + 편집 셀 높이·flush 정렬(PR #46·#49). → §6.2·§6.3.

    배포 안정성 · 보안¶

    • 배포 후 SPA stale 청크 "먹통" 자가치유(PR #37) — router.onError/vite:preloadError 로 청크 로드 실패 시 자동 복구. → 트러블슈팅 §7.
    • nginx 보안 헤더 + gzip(PR #40) — HSTS·X-Frame-Options(SAMEORIGIN)·nosniff·Referrer-Policy + 텍스트 응답 gzip.
    • CSP Report-Only 도입(PR #41·#43) — 차단 없이 위반 관찰(enforcing 전 단계). → 트러블슈팅 §8.

    기반¶

    • 문서 작성 정책 명문화(문서) — 개발자 문서 개요에 ① 사내 전용 정보(내부 IP·호스트명·계정·실운영 문서)의 공개 문서 게시 금지 ② 한국어 · MkDocs Material 조직 표준 준수 를 명시. → 개요.
    • CI 품질게이트 워크플로 추가(PR #30) — dev/main PR 에서 빌드(vue-tsc + vite build)·Trivy 의존성 CVE(리포트)·SBOM 을 실행한다. 리포트 전용·비차단. 자세히: 빌드/배포 §CI 품질게이트.
