# Vendor-Portal-V2-Frontend-docs

[Vendor Portal V2 프론트엔드](https://github.com/SinokorOfficial/Vendor-Portal-V2-Frontend)의 **사용자 매뉴얼**과 **개발자 문서** 발행 레포입니다.

- 사용자 매뉴얼: <https://sinokorofficial.github.io/Vendor-Portal-V2-Frontend-docs/>
- 개발자 문서: <https://sinokorofficial.github.io/Vendor-Portal-V2-Frontend-docs/dev/>

> ⚠️ 이 레포는 **빌드 산출물(`gh-pages` 브랜치)** 만 호스팅합니다.
> 문서 소스/설정은 코드 레포(`Vendor-Portal-V2-Frontend`)의 `docs/`·`docs-dev/`·`mkdocs*.yml`·`docs-tools/` 에 있으며,
> `main` push 시 `docs-deploy.yml` 워크플로가 자동 빌드·발행합니다. 운영 가이드는 코드 레포의 `DOCS-DEPLOY.md` 참고.
